Lokale, komplett separate Repo-Struktur für eine neue Rebell Systems B2B-Landingpage.

## Zweck
Diese Struktur wurde getrennt vorbereitet, ohne bestehende Repositories oder Websites anzufassen.

## Enthalten
- `index.html`
- `README.md`
- optionaler Platz für `assets/`
- Impressum und Datenschutz als integrierte Platzhalter
